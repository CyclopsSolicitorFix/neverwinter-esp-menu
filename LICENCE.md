## 🧩 About

**Neverwinter Companion** is a curated list of Neverwinter open-source tools:

- **Overlays** — on-screen helpers, layout notes, overlay, loot tracker
- **Quality-of-Life Helpers** — inventory organizer, map notes, config presets
- **Research Notes** — dungeon layouts and config notes for educational use

Based on publicly available community tools and overlay helpers.

---

## ✨ Features

### 🎮 Gameplay Helpers
- overlay Overlay — track nearby allies and points of interest
- Loot Tracker — log drops and resource nodes
- Map Notes — annotate dungeon layouts for study
- Speed Control — adjust movement for single-player research

### 🎨 Interface & Cosmetics
- HUD Customizer — reposition and resize UI elements
- Inventory Organizer — sort and filter items by category
- Chat Filter — categorize and highlight messages

### 🏋️ Practice Layout
- Dungeon Practice Notes — segment study on any layout
- Auto-Loot Notes — collect items in single-player sessions
- Cooldown Timer — track ability and potion timers
